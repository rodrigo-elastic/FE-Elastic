# Feature tour

Page-by-page reference. The persistent left sidebar (`frontend/assets/js/tools-rail.js`) is on every page; same shortcuts everywhere.

| # | Page | Path | Who it is for | What it does |
|---|---|---|---|---|
| 1 | Dashboard | [`/`](../frontend/index.html) | Every FE | Calendar inbox with smart resolver that filters Elastic-internal invites and deprioritizes 17+ consulting firms ([`../backend/app/services/company_resolver.py`](../backend/app/services/company_resolver.py)). Hero stats, three entry modes (Quick Research, Transcript paste, Calendar). Screenshot: [screenshots/dashboard.png](screenshots/dashboard.png). |
| 2 | Meeting workspace | [`/meeting.html?id=...`](../frontend/meeting.html) | FE running a customer call | Three tabs: pre-meeting brief, live companion, post-meeting actions. The Brief tab auto-injects the AutoOps widget that polls `/api/v1/autoops/summary` and `/api/v1/autoops/competitive` to show live cluster signals plus the AutoOps-vs-Splunk competitive card, the TAR widget for a CA-facing technical health review, the Pre-sales Playbook (Search 101 + How-NOT-to-Sell), and a Field Assistant mini-chat. Customer journey strip across the top. Screenshot: [screenshots/meeting_revolut.png](screenshots/meeting_revolut.png). |
| 3 | Tools rail | [`/tools.html`](../frontend/tools.html) | Every FE | Fourteen collapsible panels: POC plan, SPL to ES\|QL, Compliance mapper, Stack extractor, Code sample, Cost calc, Capacity, Knowledge search, Troubleshoot, Compare, Orchestrator, Proposal, Deploy validator, POV health. Each wraps a Claude expert role. Screenshot: [screenshots/tools.png](screenshots/tools.png). |
| 4 | FE Brain | [`/fe-brain.html`](../frontend/fe-brain.html) | FE asking docs questions | Retrieval-augmented Q+A grounded in the official Elastic documentation, indexed in `fec-knowledge` with ELSER embeddings. Citations link back to the source page. |
| 5 | Agent Builder | [`/agent-builder.html`](../frontend/agent-builder.html) | FE wanting tool chaining + custom tools | Chat surface for `fec_field_assistant` plus the custom-tool CRUD UI (NL drafter -> ES\|QL tool spec -> Kibana upsert). Screenshot: [screenshots/agent_builder.png](screenshots/agent_builder.png). |
| 6 | Battlecards | [`/battlecards.html`](../frontend/battlecards.html) | FE in a competitive situation | 33 battlecards plus a per-competitor specialist chat ("Ask the X Specialist") that talks to the per-competitor Kibana agent provisioned by `sync_battlecard_agents.py`. |
| 7 | Customer Health | [`/customer-health.html`](../frontend/customer-health.html) | CA hat | Per-account dashboard: cluster status, renewal proximity, ticket trend, 90-day adoption sparkline, and rule-based proactive tasks (no QBR in 4 months + AutoOps degraded -> schedule check-in). |
| 8 | Industries and Demo Data | [`/industries.html`](../frontend/industries.html) | Anyone reproducing the demo | 20-industry catalog merged with the demo-data seeder. Click any industry to open the detail modal (personas, regulations, clickable competitor chips that open battlecards in new tabs) and seed the matching scenarios (FE dashboard + Customer dashboard per scenario). |
| 9 | Workspace | [`/workspace.html`](../frontend/workspace.html) | Every FE | Kanban + timeline of every brief, post-meeting, and transcript per customer. Account handover modal with autocomplete and a live email-preview panel. |
| 10 | Workflow demo | [`/workflow-demo.html`](../frontend/workflow-demo.html) | FE leadership | Visualises the closed-loop: doc lands in `fec-transcript-inbox`, Kibana Workflow fires, webhook hits backend, post-meeting agent runs Salesforce + Slack. Screenshot: [screenshots/workflow_demo.png](screenshots/workflow_demo.png). |
| 11 | Workflow settings | [`/workflow-settings.html`](../frontend/workflow-settings.html) | FE running the loop | Enables and disables individual Kibana rules and toggles email per rule. |
| 12 | QBR | [`/qbr.html`](../frontend/qbr.html) | AE preparing a QBR | Aggregates post-meeting records and renders a four-section deck plus PPTX export. Customer data routed through Kibana inference with `strict=True`. |
| 13 | Weekly slides | [`/weekly-slides.html`](../frontend/weekly-slides.html) | FE running a weekly standup | One slide per company per week, uploads PPTX to Slack on demand. |
| 14 | POV health | [`/pov-health.html`](../frontend/pov-health.html) | FE owning a trial | Pasted POV summary returns stage assessment, confidence score, strengths, risks, four owner-assignable next-best actions. |
| 15 | Audit | [`/audit.html`](../frontend/audit.html) | Every FE | Live audit log with per-call token counts (Elastic monitoring Elastic). |
