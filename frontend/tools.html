Technical tools for Field Engineers.

Eight utilities for the technical-sales motion: POC plans, SPL to ES|QL conversion, compliance mappings, cost calculator, capacity planner, automatic tech-stack extraction, code-sample generation, and a troubleshooting assistant. Each tool is a one-shot Claude call (or pure compute) backed by structured JSON output.

Structured 4-8 week proof-of-value plan grounded in the latest post-meeting record (success criteria, phases, owners, risks).

Claude
